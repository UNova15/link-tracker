# LinkTracker

LinkTracker – Telegram-бот, который отслеживает изменения на веб-страницах и оперативно информирует пользователя о них.

# Инструкция по запуску

Для запуска требуется установленный docker и docker compose
Необходимо создать файл .env в корне проект и определить в нем 4 переменные:

- TELEGRAM_BOT_TOKEN - токен тг бота
- GITHUB_TOKEN - токен github
- STACKOVERFLOW_KEY - ключ stackoverflow
- STACKOVERFLOW_ACCESS_KEY - ключ доступа stackoverflow
- AI_TOKEN - токен аккаунта, созданный в hugging face для использования ии модели

Запуск из корня проекта: docker compose up

Предполагается выбор режима работы в настройках application.yaml:

- app.db-provider - провайдер базы данных : orm (spring jpa hibernate) или sql

Гарантии доставки сообщения об изменениях - exactly once. Реализовано путем реализации семантики at least once и
обеспечение идемпотентности с помощью детерминированный ключей идемпотентности генерируемых как на стороне scraper так и
на стороне ai-agent для устранения любых возможных дублей сообщений.

Каждый микросервис является stateless (за исключением функции rate limiting для которой используется локальный кеш) что
позволяет масштабировать систему (например добавление новых реплик какого либо микросервиса) без серьезных проблем.
